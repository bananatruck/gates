\begin{abstract}
Autonomous research agents write papers that report numbers their experiments never produced.
In Agent Laboratory, the scaffold we audited, the cause was mechanical.
The host cut experiment output to a short prefix before any agent read it, so the writer never saw the real numbers and the failure detector never saw the crash.
We argue that a large share of fabricated results is an information-flow defect, and we close the channel at three points with \gates{}: execution validity, source-result coherence and report validity.
Deterministic checks decide every verdict, each rejection goes back to the agent as a list of fixes, and the layer installs into a host through one adapter.
In a signed campaign, Gate 1 delivered 40 of 40 required values to the writer, against 0 of 40 without it.
On one MLR-Bench task, at four cumulative levels and two seeds, an agent's reading of code and logs finds results that no execution produced in both ungated papers and in none of the six gated ones.
At least one of two agent judges still flags each gated paper, mostly for prose that misstates a number the run did measure, which no gate checks.
Level 3 cost 2.21 times level 0 and took 2.59 times as long, and 46 of 59 crashes were caused by our harness, not the agent.
A red team shows the limit plainly: 10 of 18 fabrication strategies pass silently.
\end{abstract}

\section{Introduction}

Research agents such as Agent Laboratory~\cite{schmidgall2025agentlab} and The AI Scientist-v2~\cite{yamada2025aiscientistv2} run experiments and then write the papers that report them.
Those papers often report results that no experiment produced.
MLR-Bench's released human labels mark faked experimental results in all ten papers that AI Scientist-v2 wrote for the benchmark's full research tasks~\cite{chen2025mlrbench}.

The usual explanation is that the model fabricates.
In the Agent Laboratory scaffold we audited, the cause was plainer.
The host cut experiment output to a short fixed prefix before any agent read it.
It also appended the crash marker after the program's own output, so the same cut dropped the marker.
The writing agent never saw the numbers, and the failure detector never saw the crash.
A model in that position has nothing true to report, so it reports something else.

That makes much of the fabrication a property of the information flow, and a deterministic layer can stop it.
\gates{} places a gate at each point where a scaffold loses its hold on evidence:

\begin{itemize}
\item \textbf{Gate 1, execution validity.} Did the code run, and did this run produce the numbers?
Only the values the experiment recorded can be cited.
\item \textbf{Gate 2, source-result coherence.} Is the verified run consistent with the ranges, relations and methods its plan declared?
\item \textbf{Gate 3, report validity.} Does every number in the manuscript render from a recorded value, and does every citation resolve to a paper the run retrieved?
\end{itemize}

We claim a large share, not all.
Two experiments would test the stronger claim, and neither has run yet.
The first is L0', which delivers Gate 1's evidence to the agent but never enforces its verdict, and so separates delivering the values from rejecting runs.
The second is a second model under test.
L0' exists in the layer, but the host cannot run it until it accepts the new level.

Our end-to-end result is narrow.
On one task, by an agent's reading, the gates turned invented numbers into measured numbers, but they do not check what the prose says about those numbers.
A gated paper can still say that a value ``never exceeds'' a bound its own table breaks; we show where this happens and propose the next check.

Our contributions are:
(1) three gates whose verdicts no model can change, each with a feedback loop back to the agent;
(2) a cumulative switch that runs the gates one at a time, so each gate's effect is measured rather than assumed;
(3) mechanism evidence for each gate, a red team of 18 fabrication strategies, and 63 probes of Gate 3's token check;
(4) a first comparison on one MLR-Bench task at all four levels, with crashes split by cause, cost, and agent judges;
and (5) the forward evaluation on Hidden Pitfalls~\cite{luo2025hiddenpitfalls}, with the published numbers it will be read against.

\section{Related Work}

\paragraph{Research agents.}
Agent Laboratory~\cite{schmidgall2025agentlab} and The AI Scientist-v2~\cite{yamada2025aiscientistv2} automate the path from idea to paper.
ScientistOne~\cite{scientistone2026} keeps chains of evidence through its own pipeline and audits other systems' released papers after the fact.
Its checks include score verification, specification violation and reference verification, which line up with our Gates 1, 2 and 3.
The difference is where the check sits.
\gates{} runs inside an existing scaffold, acts before the paper exists, and sends each rejection back to the agent that can fix it.

\paragraph{Benchmarks.}
MLR-Bench~\cite{chen2025mlrbench} evaluates agents on open-ended machine-learning research, scores their papers with an LLM judge, and labels four kinds of hallucination with human confirmation.
Hidden Pitfalls~\cite{luo2025hiddenpitfalls} probes four failures of AI scientist systems: inappropriate benchmark selection, data leakage, metric misuse and post-hoc selection bias.
It also shows that an LLM auditor finds them far more often when it reads the logs and code than when it reads the paper alone, which is the published case for checking evidence rather than prose.
BadScientist~\cite{jiang2025badscientist} shows that LLM reviewers accept fabricated papers with no experiments at high rates under presentation-level manipulation.
CORE-Bench~\cite{siegel2024corebench} asks agents to reproduce published code and answer questions about its outputs; it has no manuscript, so Gate 3 would have nothing to read.

\section{The \gates{} Design}

\subsection{Invariants}

The layer uses the Python standard library only, imports nothing from the host, and receives the model as one injected function.
Deterministic checks decide every verdict.
A model can add a warning and nothing else, because the function that records a model's finding fixes its severity at WARN and takes no severity argument.
A check with no input emits nothing, so a report never shows a green row for a check that did not run.
A gate never modifies what it judges; it writes its evidence beside it, and its ledger records every attempt, accepted or not.

\subsection{Three gates}

\paragraph{Gate 1, execution validity.}
The experiment program records each result with \texttt{record\_result(key, value)} and each configured value, such as a learning rate, with \texttt{record\_setting}.
Gate 1 runs the program in a child process.
It checks that the run exited cleanly with no swallowed traceback, that the expected keys are present, finite and not degenerate, and that a static pass over the code finds each recorded value computed rather than typed as a constant.
Accepted values go into a registry, which is the only source of citable numbers downstream.
The writer receives the registry, the settings, the warnings and a path to the full output, in place of the host's printout.
A log scanner and an optional model layer add warnings that never change the verdict.

\paragraph{Gate 2, source-result coherence.}
Gate 2 reads the registry against what the plan declared.
Tier A checks the registry on its own terms, such as ranges and relations between keys.
Tier B checks the run against plan fields.
A model extracts those fields from the host's free-text plan and keeps only fields whose quote appears in the plan, so a divergence on such a field is capped at a warning.

\paragraph{Gate 3, report validity.}
The writer cites a result as \verb|\result{key}| and a setting as \verb|\setting{key}|, and Gate 3 renders each token from the registry.
It fails a manuscript that types a numeral in its results sections, names a key the run did not record, or types a digit, a sign or a power of ten against a token.
It also checks that referenced figures exist, that Gate 2's declared limitations appear word for word, and that every cited arXiv identifier resolves and was retrieved by the run.
Gate 3 runs nothing.
It writes each rendered number's claim chain, from task to command to log to value to claim.

\subsection{Levels and L0'}

One environment variable, \texttt{GATES\_LEVEL}, selects level 0 (all gates off), 1 (Gate 1), 2 (Gates 1 and 2) or 3 (all three).
The levels are cumulative because each gate reads what the one before it produced: Gate 2 reviews Gate 1's registry, and Gate 3 judges a manuscript against it.
A closed gate raises before it spends an agent turn, so no setting runs a gate without the gates below it.
Level 0 is the host as shipped.
L0' (\texttt{GATES\_LEVEL=0d}) behaves as level 0 in every decision, but Gate 1 runs and its evidence reaches the agent in place of the host's prefix; its verdict decides nothing.

\subsection{Feedback loop and exhaustion}

Each gate runs a reject, fix and retry loop.
A rejection is rendered as a report the agent can act on: which check failed, on which key or line, and what to change.
The budget lives in the adapter, not in the gate, and the person wiring the layer chooses it after the setup step states its cost.
The policies on a spent budget differ on purpose (Table~\ref{tab:exhaustion}).
Gate 2 must not block a new result forever, while an unverifiable experiment or manuscript must not be emitted.

\subsection{Installing into a host}

The loops every host shares live in the layer itself.
A host adapter supplies only host knowledge: a context per phase, the host's model call, its original execution path for level 0, and the identifiers of the papers it retrieved.
The install path ships as agent skills, a router and one skill per gate, each naming what it needs from the gate before it and what it hands on; a test holds each skill to the code it describes.
The layer's suite holds 994 tests and refuses every network socket.
Agent Laboratory is the only host so far; an adapter for a second host is future work.

\section{Evaluation Design}

We report two kinds of evidence and never mix them in one figure.
Mechanism evidence measures what each gate catches and what it wrongly flags, on a signed campaign and on model-free rigs.
End-to-end evidence comes from two waves of real runs on one benchmark task.

\paragraph{Waves 2 and 3.}
The host is Agent Laboratory, and the model under test is \texttt{deepseek-flash} (DeepSeek V4.1 Flash).
The task is MLR-Bench's \texttt{iclr2025\_scsl}.
A wave starts all four levels together on one machine with one seed; wave 3 is seed 1 and wave 2 is seed 2.
The GPU is split four ways, 0.9/4 of the device per run.
Each run stops at \$5.50 of measured cost, and every gate allows 10000 rewrites, so a run is bounded by cost rather than by attempts.
Only sterile runs enter a table, runs that start from the pinned inputs with their own empty caches and folders; a wave with an outside failure or a broken sterile condition is void and is rerun at the same seed.
Wave 1 and one voided wave are kept out of every table; they cost \$1.78 and \$1.1537.
All eight runs completed and wrote a paper.
The waves ran at a gates commit from before the fixes of 29 September, including the separate call for settings, so their verdicts are those of that version.

\paragraph{Agent judges.}
Two agent judges score each paper with MLR-Bench's prompts: Claude Opus 5.5 through Claude Code, and GPT-5.6 Sol at high effort through Codex.
Each gives an MLR-Judge overall score from 1 to 10 and lists hallucinations by type, including ``Faked Experimental Results''.
Like MLR-Bench's judge, they read the paper, the task and the code, but not the logs.
Grok 4.7 through Cursor gives an opinion with the same prompts; it is recorded and never counted.
Every judgement is tagged \rtag{}: no person has confirmed any flag yet.
A paper that every judge flags is a faked-results candidate, and a person decides whether it counts.
One run is incomplete: on level 3, seed 2, Codex's faked-results answer failed on a credit limit, and its overall score has no source file, so that run has Opus's verdict only.
\todo{Rerun Codex on L3 seed 2 once it has credits, then redraw Figure~\ref{fig:judge} and Table~\ref{tab:faked}.}

\paragraph{Statistics.}
Each task and seed gives one pair of level 0 and level 3 runs.
Two pairs cannot reach the planned test: the smallest exact two-sided McNemar $p$ with two discordant pairs is 0.5.
So everything in Section~\ref{sec:waves} is descriptive.
The full study's test was fixed before the pilot: an exact McNemar test on the discordant pairs per benchmark, Holm's correction across the benchmark family, and a paired-bootstrap non-inferiority bound on the task score.

\paragraph{Gate 1.}
In the signed campaign, Gate 1 delivered 40 of 40 required key-value pairs to the writer, against 0 of 40 through the host's prefix.
With Gate 1 on, 10 of 10 attempts delivered all four required values, against 0 of 10, and the paper reported 4 of 4 of them as numbers, against 0 of 4.
In the gated manuscript, 28 of 29 claims traced to the registry or to a checkable derivation, against 0 of 11 in the ungated one.
Re-read under the later claim scanner, the same gated paper traces 34 of 37.
Delivering the evidence did not make the paper better: the final reviewer scores were 3.735 gated and 3.765 ungated.
Gate 1's log scanner, on 68 labelled lines holding 34 signals, has precision 1.000 and recall 0.529 with its deterministic patterns alone, and recall 0.882 at precision 1.000 when a three-shot \texttt{qwen3:8b} adds warnings.
Against 232 agent-written experiment files on our machine, with 3667 record calls, the latest static checks changed no classification.

\paragraph{Gate 2.}
On labelled rigs, tier A rejected 27 of 27 defective registries and wrongly rejected 0 of 18 clean ones.
Tier B caught 12 of 12 plan divergences with 0 false alarms in 17, and flagged 6 of 6 unverifiable fields with 0 false alarms in 23.
We built these cases, so they measure the checks on the defects we thought of.

\paragraph{Gate 3.}
The claim scanner detects 46 of 49 typed result literals in two archived manuscripts, with 8 false positives.
It misses 3: two small integers and a value stated twice on one line.
The earlier scanner, which skipped any line holding a reference, detected 34 of the same 49.

\paragraph{Red team.}
A fixed, model-free rig plants a fabricated test accuracy in an experiment program in 18 ways, plus an honest control, and runs each once through Gate 1 (Figure~\ref{fig:redteam}).
Seven are blocked, among them a literal typed at the recording call or passed through a variable, a dictionary or a reducer.
One is warned: every epoch recorded under one key with the best last.
Ten pass silently.
Six of those are choices of method on real computation: a random number in a plausible band, a measurement nudged upward, the best epoch reported as final, a failed seed dropped from the mean, the best of five seeds, and training accuracy labelled as test.
No check on a recorded value can see them, because each value is what the code computed.
Three are limits of the static pass: a result recorded as a setting, a literal passed through tuple unpacking, and a literal returned by a function the program defines.
The tenth records a typed constant through an alias of the recording call.

\paragraph{Adjacency probes.}
Gate 3's token-adjacency check fails a manuscript whose typed notation changes a token's rendered value, such as a digit typed right after \verb|\result{x}|.
We probed it with 27 attack shapes and 36 honest shapes (Figure~\ref{fig:adjacency}).
It caught 23 of 27 attacks and passed 35 of 36 honest shapes.

\paragraph{What the papers report.}

Take level 3, seed 1, which both judges flag.
The prose says the CNN's saliency share never exceeds the value it takes under the full shortcut, and the paper's own table shows higher values at two weaker shortcut strengths.
Opus also flags the title's ``threshold that transfers'': the worst-group accuracy around the claimed threshold is not monotone, the largest drop comes at a different strength, and nothing in the paper tests transfer.
The numbers in those sentences are the run's own.
The agent's trace finds all but 1 of the 418 numerals of that paper in the execution that fed its writer, and the paper prints its $p$-values to 17 significant digits because each renders the registry's unrounded value.
What is wrong is the sentence about the numbers.
The other gated flags are also claims about measured numbers: a range the table breaks, a trend called monotone that ends negative, a forced choice among digit tokens called exact match.
Two Codex flags at level 2 sit nearer the line between the rules: a sweep presented as replicated across seeds that the code ran once, and two methods called identical with no comparison in the code.
They describe results the code never measured.
The agent's reading behind the rule A row was made from the Opus judge's files and does not discuss these two claims, so a person has to place them.

The gates check that a number was measured, not what a sentence claims about it; we deferred claim entailment past this paper.
So at level 0, by an agent's reading, the papers report numbers no execution produced, and at levels 1 to 3 the numbers are measured and the defect left is claims about them.
The next check follows from the flags.
A sentence that states a bound, a range, an order or a trend over result tokens can be checked deterministically against every registry value of the same key, and a seed count can be required to render from a recorded setting.
Prose with no tokens would go to model-assisted entailment, which under our invariants can only warn.
We have not built this check.

\paragraph{Citations.}
The same agent's reading resolved all 63 distinct arXiv identifiers across the eight papers.
Three references at levels 1 and 2 attach a real identifier to the wrong title, authors or paper, and a fourth carries a title and authors that an arXiv title search did not find.
Gate 3 checks that an identifier resolves and was retrieved, not that the title beside it is right, and it is closed at levels 1 and 2.

\paragraph{Hidden Pitfalls.}
Hidden Pitfalls~\cite{luo2025hiddenpitfalls} has published numbers for Agent Laboratory, our host, on its own probes.
It measures four pitfalls; two of them, data leakage and metric misuse, are ones a gate can change.
Data leakage counts runs whose reported test accuracy exceeds what the injected label noise allows, or whose code subsamples or synthesises data.
The authors report that Agent Laboratory's run 16 evaluated on an undisclosed subset, and run 11 on undisclosed synthetic data.
Metric misuse counts papers that report only one of the two metrics the task names.
On the task that names SWA first, 100\% of Agent Laboratory's runs report test SWA only, in both noise settings.
The paper's auditor reaches 55.0\% accuracy from the paper alone and 82.0\% with the logs and code (Fisher $p = 6.3 \times 10^{-5}$).
We will first check that deterministic scorers reproduce the published runs from the authors' released Agent Laboratory outputs.
We will then run the authors' auditor prompts through our agent judges over our eight runs, with paper, code and logs; our task differs from theirs, so this transfers the instrument and we will say so.
Per-level runs on the two probes need host changes and come last.
The auditor driver is built and reviewed, the scorers are being built, and no result exists yet.
Our MLR-Bench task names no metric and offers no benchmark list, so the probes cannot score waves 2 and 3.
The red team's six silent method-level strategies suggest this benchmark may mostly measure the gates' limits, which is a reason to run it.

\section{Limitations}

\paragraph{Cheating with real numbers.}
Ten of the red team's 18 strategies pass silently.
Six cheat in the method while every recorded value is real, which no check on a recorded value can see; four are limits of Gate 1's static pass.

\paragraph{Claims about numbers.}
The gates check that a number was measured, not what a sentence says about it.
Every gated faked-results flag in waves 2 and 3 is a claim about measured numbers or about how they were measured, and Section~\ref{sec:waves} proposes the check that would catch most of them.

\paragraph{Gate 3's blind spots.}
Four of the 27 adjacency attacks pass, stated as a \texttt{\# limit:} comment in \texttt{gates/gate3.py}.
A test-design pass found four more shapes that Gate 3 passes, still open: a numeral inside a citation's optional text or a cross-reference's link text, inside an equation or a figure caption, in a section heading, and behind a macro the manuscript defines.
The claim scanner misses 3 of 49 literals.
Citation checks see arXiv identifiers only, and check that an identifier resolves and was retrieved, not that the title beside it is right.

\paragraph{Scale.}
The end-to-end result is one task, one model and two seeds, so it is descriptive.

\paragraph{The harness.}
Our harness caused 46 of the 59 crashes, mostly through the GPU cap of a four-way split and through timeouts, so crash counts compare harness conditions as much as agents.
We report crashes by cause and attribute only the agent's to the agent.

\paragraph{Cost.}
Level 3 cost 2.21 times level 0 and took 2.59 times the wall clock, with 2.30 times the tokens.
A quality difference between levels is therefore also a compute difference.

\paragraph{Judges.}
Every judgement so far is an agent's, \rtag{}, and one is incomplete.
Like MLR-Bench's judge, ours do not read the logs.
A person's blind review hides the level but not the paper's text, which can still reveal its treatment.

\paragraph{What the gates do not do.}
The gates deliver the evidence; they do not make the science good, and the agent judges score every paper 1 to 3 out of 10.
The signed campaign ran on an earlier DeepSeek Flash model than the waves, so it is context for level 1, not a replication.

\section{Conclusion}

Fabricated results in the scaffold we audited came from a channel that never showed the writer the numbers, and \gates{} closes it with three deterministic gates installed through one adapter.
On one MLR-Bench task, by an agent's reading, both ungated papers report results no execution produced and none of the six gated papers does.
What the gates leave is prose that misstates a measured number, and we have named the check that would catch it.
Next come that check, an L0' wave, a second model, a person's review of the judges' flags, and Hidden Pitfalls.
