# G.A.T.E.S. branch audit website

Open `index.html` directly in a browser, or serve the repository locally:

```bash
python -m http.server 8000 --directory reports/branch-audit
```

Then visit `http://127.0.0.1:8000`.

The report is dependency-free, responsive, print-ready, and links to immutable GitHub commit SHAs and primary paper records. Use the **Print report** button to save a PDF.
