EXPERIMENT EXPLANATION (detailed):
This controlled data-efficiency experiment trains multinomial logistic
regression on two fixed fractions of a 400-sample labelled training pool.
  Arm 25%  -> first 100 samples of the pool (25% of the labelled data).
  Arm 100% -> all 400 samples of the pool (full labelled data).
Both arms use identical setups: multinomial logistic regression with a
bias column, zero-initialized weights, full-batch gradient descent with
learning rate 0.1, exactly 1500 update steps, and the same fixed 200-sample
held-out test set. The synthetic data itself is drawn once with seed 42
(600 samples, 8 features, 3 balanced classes with fixed class centers).
Because every training-related factor except the amount of labelled data
is held constant, any difference in held-out test accuracy directly
quantifies the data-efficiency of the model on this 3-class, 8-feature
classification task.

The headline metric  eff.efficiency_ratio = eff.acc_at_25 / eff.acc_at_100
states what fraction of the full-data test accuracy is already achieved
with only one quarter of the training data. A ratio near 1.0 indicates the
model saturates quickly and the extra 300 samples add little; a ratio well
below 1.0 indicates the remaining data provides a substantial accuracy gain.

LEARNING-CURVE SATURATION ANALYSIS EXPLANATION:
Following the learning-curve literature (e.g., arXiv:2102.09382), we
additionally train the same multinomial logistic-regression model on
multiple prefixes of the 400-sample training pool (25 to 400 samples),
always with the same zero initialization, lr=0.1, and 1500 full-batch
gradient-descent steps. We then fit the inverse power law
    acc(n) = alpha - beta * n^gamma   (gamma < 0)
to the measured test accuracies. alpha is the extrapolated asymptotic
accuracy as n -> infinity. This quantifies how much of the full-data
performance is already captured at 100 samples (the 25% arm) and where
the model saturates, directly supporting the main efficiency ratio.
