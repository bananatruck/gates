Experiment purpose:
This controlled data-efficiency gate isolates the effect of training-set
size on test accuracy. Both arms use the exact same multinomial logistic
regression model (softmax + cross-entropy), vanilla gradient descent,
identical seed (42), identical initial zero weights, identical learning
rate (0.1), and identical number of gradient steps (300). The only
difference is the number of training samples: Arm A sees 100 labelled
samples (25% of the 400-sample pool) while Arm B sees all 400 samples.
Both arms are evaluated on the same frozen 200-sample test set, so any
accuracy gap is attributable solely to data quantity. The headline metric,
eff.efficiency_ratio = acc_at_25 / acc_at_100, measures how much of the
full-data accuracy is retained when only a quarter of the labels are used.

Evaluation explanation:
After the full 300-step training, each arm's learned weight matrix is
frozen and applied to the fixed 200-sample test set. Test accuracy is the
fraction of argmax predictions that match the true class labels. From the
two accuracies we compute eff.efficiency_ratio = acc_at_25 / acc_at_100.
A ratio below 1 shows that more data helps; the magnitude tells us how
much classification quality is lost when only 100 of the 400 labels are
used. The wallclock time eff.train_s covers only the two training loops,
so it is a direct measure of the computational cost of the comparison.
